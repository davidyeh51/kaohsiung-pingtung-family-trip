# 🌕 2026 高屏中秋家庭慢活遊 (9/25~9/28)

> 專為夫妻兩人與 **17 個月大可愛女兒** 量身打造的高雄 ＆ 屏東中秋連假溫馨家庭假期。
> 涵蓋：爸爸俐落剪髮、素娥阿媽與阿榮阿公天倫探望、Nancy 外婆一家外帶汕頭火鍋圍爐、屏東森林總圖與全冷氣西市場、以及高雄展覽館「臺灣國際兒童及青少年嘉年華」未來世代書展！

## 📌 行程關鍵微調與亮點

1. **Day 1 (9/25 五)：爸爸剪髮 ＆ 探望素娥阿媽 ＆ 汕頭火鍋**
   - 10:00~11:00：爸爸前往「呼宅時光」（苓雅區金門街31號）由設計師 Pony 洗加剪（$850），換個俐落髮型迎接家人。
   - 14:00：老婆與小女兒由丈母娘（Nancy外婆）開車平安送抵高雄，爸爸接風搬運行李。
   - 16:00~18:00：帶 17M 小女兒回老家看「素娥阿媽」，祖孫見面阿媽笑開懷。
   - 18:00~20:30：外帶高雄知名汕頭沙茶火鍋，回家與 Nancy 外婆一家人熱鬧圍爐。

2. **Day 2 (9/26 六)：國境之南 ‧ 屏東森林圖書館 ＆ 雙市集**
   - 屏東總圖 1F 兒童閱讀專區脫鞋翻繪本、勝利星村老屋午餐。
   - 寶寶車上午睡 1.5 小時，午後逛全冷氣綠建築「屏東西市場」與高架橋下遮陰「萬倉街 NEKO MARKET」。

3. **Day 3 (9/27 日)：長輩雙向圓滿 ＆ 帶回家吃飯哄睡**
   - 10:00~12:00：全家帶女兒探望「素娥阿媽與阿榮阿公」，三代同堂共享中秋天倫。
   - 下午：讓老婆帶女兒去找 Nancy 外婆玩耍，外婆牽著外孫女小手堆積木吃點心，爸爸享受彈性休憩時光。
   - 晚上：帶回家吃飯及哄睡！爸爸協助餵食剪碎料理、放洗澡水、喝睡前奶並輕拍背背哄睡，維持幼兒穩定作息。

4. **Day 4 (9/28 一)：高雄展覽館兒少書展 ＆ 再訪外婆**
   - 上午：前往高雄展覽館參加文化部主辦「2026年臺灣國際兒童及青少年嘉年華」未來世代書展（自由玩餐桌、繪本館、小王子80週年特展），全館無障礙平坦冷氣涼爽，18歲以下免費！
   - 下午：讓老婆帶女兒去見 Nancy 外婆玩，把握連假最後半天陪伴外婆。
   - 晚上：全家清淡晚餐，翻閱新買的童書，早早入眠迎接開工。
