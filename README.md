# 🌕 2026 高屏中秋家庭慢活遊 (9/25~9/28)

> 專為夫妻兩人與 **17 個月大可愛女兒** 量身打造的高雄 ＆ 屏東中秋連假溫馨家庭假期。
> 涵蓋：爸爸俐落剪髮、下午專注居家整理拆箱、Nancy 外婆一家外帶汕頭火鍋圍爐、屏東森林總圖與全冷氣西市場、9/27 老婆赴鼓山三山燒肉林家聚餐逛街、爸爸 17 點帶女兒見素娥阿媽（20點前歸）、以及 9/28 整天爸爸專屬休息日、媽媽帶女兒找 Nancy 阿媽玩耍！

## 📌 行程關鍵微調與亮點

1. **Day 1 (9/25 五)：爸爸剪髮 ＆ 專注居家整理 ＆ 汕頭火鍋圍爐**
   - 10:00~11:00：爸爸前往「呼宅時光」（苓雅區金門街31號）由設計師 Pony 洗加剪（$850），換上清爽帥氣髮型。
   - 14:00：老婆與小女兒由丈母娘（Nancy外婆）開車平安送抵高雄，爸爸接風搬運行李。
   - **下午取消見素娥阿媽**：專注居家整理、拆箱歸位，讓母女在涼爽舒適的家中放鬆適應。
   - 18:00~20:30：外帶高雄知名汕頭沙茶火鍋，回家與 Nancy 外婆一家人熱鬧圍爐。

2. **Day 2 (9/26 六)：晨間居家休整 ＆ Q哥貼膜 ＆ 屏東質感市集**
   - 上午：修正為居家休整，全家睡到自然醒，地墊共讀繪本；午餐後讓小女兒在家安穩午睡至約 **14:00** 充電。
   - 下午：14:00 出門首站前往 **「Q哥」** 門市為老婆手機換保護貼/包膜，再經台88直奔全冷氣綠建築 **「屏東西市場」** 與高架鐵路橋下全遮陰 **「萬倉街 NEKO MARKET」**。
   - 晚上：享用屏東在地鮮魚海鮮粥晚餐，19:30 平安返回高雄。

3. **Day 3 (9/27 日)：老婆三山燒肉聚餐逛街 ＆ 爸爸 17 點見素娥阿媽**
   - 上午：全家居家休息放鬆，享受慵懶晨光。
   - 中午/下午/晚上（老婆）：13:30~15:30 赴鼓山區博愛二路「三山燒肉」參加林家聚餐，餐後與家人逛街放風至晚上才回家。
   - 下午/傍晚（爸爸與女兒）：下午寶寶午睡充電；**17:00 爸爸開車帶小女兒回素娥阿媽家（看素娥阿媽＋阿榮阿公，三代同堂共享天倫）**，**20:00 之前準時帶女兒回家**，洗澡、喝睡前奶哄睡！

4. **Day 4 (9/28 一)：整天爸爸休息日 ＆ 媽媽帶女兒找 Nancy 阿媽玩**
   - ★ **整天爸爸休息日**：爸爸在家徹底放鬆、補眠、喝咖啡、追劇，零行程壓力充電。
   - **媽媽帶女兒找 Nancy 阿媽（外婆）玩**：全天在外婆家享受親密陪伴天倫，外婆疼孫。
   - 晚上：全家清淡晚餐，圓滿收心中秋連假！
