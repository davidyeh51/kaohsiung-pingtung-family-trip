## 🌤️ 高屏中秋連假即時氣象資料看板 (9/25~9/28)

網頁首頁置頂即時氣象看板，出發前一目了然：
- **高雄市區**：🌤️ **26°C ~ 32°C**（晴時多雲，午後海風舒暢，日落 17:58，滿月升起澄澈）。
- **田寮月世界**：🌡️ **24°C ~ 31°C**（早晚溫差約 7°C，微風 2 級極適宜熱氣球升空，建議備遮陽帽與草本防蚊液）。
- **屏東市區**：🌳 **25°C ~ 32°C**（綠建築西市場室內冷氣充足，萬倉街高架鐵路橋下全遮陰，防曬避暑兼得）。
- **9/28 在家休整日**：🛋️ **室內舒適 26°C**（不趕行程、避開人潮車潮，客廳地墊玩積木、嬰兒床熟睡 2 小時）。

## 📌 行程關鍵微調與亮點（符合家庭與 17M 幼兒需求）

1. **第一天迎賓：丈母娘開車平安送回高雄（14:00 抵達）**：
   - 爸爸預先整理迎賓環境、冷氣先行開啟除濕、準備溫水與幼兒點心。
   - 14:00 丈母娘送抵高雄，爸爸主動搬運行李、向丈母娘表達滿滿感謝，迎回妻女立刻開冷氣小憩，17M 女兒喝奶換尿布。
   - 傍晚 16:00 漫步駁二大港橋，搭乘 2 站無障礙輕軌看海港夕陽；晚餐外帶鹽埕區「鴨肉珍」無刺去骨鴨肉與米血回房自在吃，大人賞月放鬆零壓力。

2. **第二天跨縣市文創：屏東森林總圖 ＆ 全冷氣綠建築西市場 ＆ 橋下市集**：
   - 車程僅 35 分鐘抵達屏東，走訪被千棵樟樹包圍的「屏東縣立圖書館總館」，1F 鋪設木地板兒童閱讀專區，軟墊地毯上翻厚紙繪本爬行。
   - 中午在勝利星村日式庭園老屋品嚐清燉雞湯麵線與滑嫩蒸蛋。
   - 午後寶寶在冷氣車內汽座上安穩午睡 1.5 小時；15:00 抵達**「屏東西市場」**，在全新綠建築中央空調下推車逛「即刻月圓．好市」文創市集；16:45 順遊高架鐵路橋下全遮陰的**「萬倉街 NEKO MARKET」**百攤文創萌寵市集。

3. **第三天重頭戲：田寮月世界熱氣球 ＆ 爸爸單挑 17M 女兒浪漫約會夜**：
   - 上午朝聖 2026 高雄愛‧月熱氣球 **28公尺「巨萌高雄熊熱氣球」**，平地合影超萌！中午享用田寮土雞城蒜頭雞清湯泡飯與手工麵線。
   - 下午寶寶車上秒睡充電，回市區梳洗，16:30 爸爸開車送老婆赴家族聚餐（與丈母娘及親友歡聚）。
   - **🌟 晚上：爸爸 ＋ 17M 女兒專屬約會夜**：
     - 基地鎖定高雄**「義享天地」**，享受 5F/6F 頂級育嬰室（冷熱水、溫奶器、軟墊尿布台）。
     - 晚餐挑選丸龜製麵/大戶屋，用食物剪剪碎烏龍麵＋現蒸鮮甜茶碗蒸，爸爸單手餵食輕鬆自如。
     - 飯後推車在 5F 看展示模型小火車、喝無糖優格，自拍甜蜜照片傳給老婆安心聚會。
     - 20:30 回房放小鴨泡澡、21:00 睡前奶、白噪音拍背哄睡，等老婆開懷歸來！

4. **第四天（9/28）連假休整日：不出遊 ‧ 在家放鬆充電**：
   - 取消鬧鐘睡到自然醒，享用現磨手沖咖啡與現烤熱壓起司吐司、寶寶鮮奶蒸蛋與香蕉泥。
   - 分工洗滌旅行衣物、拆開伴手禮；17M 小女兒在熟悉的嬰兒床上熟睡 2 小時補充元氣。
   - 晚上在家煮手工水餃與溫暖鮮魚蔬菜湯，全家精神飽滿、零疲勞迎接收假。
